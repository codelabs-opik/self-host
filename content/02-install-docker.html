Step 1 · Prerequisite

Install Docker Desktop

Opik runs as a set of containers, so you need Docker. On Mac and Windows, Docker Desktop bundles everything (the engine + Docker Compose) in one installer.

1 · Download & install

Grab the installer for your OS from the official page, then run it and follow the prompts:

→ docker.com/products/docker-desktop

🐧
On Linux? Install Docker Engine + the Compose plugin from docs.docker.com/engine/install instead. Docker Desktop is optional.

2 · Launch it

Open Docker Desktop and wait until the whale icon in your menu bar / system tray stops animating and says “Docker Desktop is running.”

3 · Confirm it works

Open a terminal and run these three commands:

terminal
docker --version
docker compose version
docker run hello-world
✔ Verify before moving on
  • docker --version prints a version (e.g. Docker version 27.x)
  • docker compose version prints a version
  • docker run hello-world ends with “Hello from Docker!”
⚠️
If a command says “command not found” or “Cannot connect to the Docker daemon,” Docker Desktop isn't running yet. Launch it, wait for the whale to settle, then retry.
