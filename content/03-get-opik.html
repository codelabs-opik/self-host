Step 2 · Download

Get the Opik project

Opik ships a small launcher script that wires up all the containers for you. You just need the repository on your machine.

Clone the repository

terminal
git clone https://github.com/comet-ml/opik.git
cd opik
📁
No Git installed? Download the ZIP from the Opik GitHub page (Code ▸ Download ZIP), unzip it, then cd into the opik folder.
✔ Verify before moving on
  • You're inside the opik folder (run pwd to check)
  • You can see the launcher: ls opik.sh (Mac/Linux) or dir opik.ps1 (Windows)
