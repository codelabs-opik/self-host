Getting started

Run Opik on your own machine

Opik is an open-source platform from Comet for tracing, evaluating, and monitoring LLM apps, RAG pipelines, and agents. In this codelab you'll stand up a full Opik instance locally with Docker, starting from nothing, and trace your first LLM call.

What you'll do

  • Install Docker Desktop and confirm it runs
  • Clone Opik and start it with a single command
  • Open the Opik dashboard at http://localhost:5173
  • Connect the Python SDK to your local instance
  • Run a script that calls any LLM and see the trace appear

Before you begin

🕐 ~30 minutes 💻 macOS · Windows · Linux 🧠 ~4 GB free RAM 📦 ~5 GB free disk ⌨️ Basic terminal use
💡
No prior Docker experience needed. Every command is spelled out. If you get stuck, each step ends with a Verify checklist so you always know your status.
