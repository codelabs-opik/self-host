Step 3 · Launch

Start Opik locally

One command pulls the images and starts every service. The first run takes a few minutes while Docker downloads them. Later starts are quick.

Start the platform

terminal
./opik.sh
powershell
powershell -ExecutionPolicy ByPass -c ".\opik.ps1"
💡
Keep this terminal open. It's running Opik. When the script finishes it prints the URL and confirms the services are healthy.

Open the dashboard

Once it's up, visit:

browser
http://localhost:5173

Health check (optional)

In a second terminal (inside the opik folder) you can confirm all services are healthy:

terminal
./opik.sh --verify

You should see every container reported as healthy:

terminal · expected output

💾
Your data lives in the ~/opik folder, so you can stop and start Opik anytime without losing anything.
