Step 4 · Configure

Connect the Python SDK

To send traces from your code, install the Opik SDK and point it at your local instance. We'll also install LiteLLM so the next step can call any LLM provider.

1 · Install

terminal
pip install opik litellm
🐍
Using a virtual environment is recommended: python -m venv .venv then source .venv/bin/activate (Windows: .venv\Scripts\activate).

2 · Point Opik at your local server

terminal
opik configure --use_local

This writes a ~/.opik.config file that tells the SDK to talk to http://localhost:5173/api, your self-hosted instance, no account or API key needed.

It then asks which project to log traces to. Accept the suggested default by typing Y, or type n to name your own (for example quickstart):

terminal
Do you want to use "Opik Demo Agent Observability" project name? (Y/n)n
Please enter the project name: quickstart
✔ Verify before moving on
  • pip show opik lists the installed version
  • A ~/.opik.config file exists pointing at localhost:5173
