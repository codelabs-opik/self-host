Step 5 · Inference

Run your first traced inference

Now the payoff: call an LLM and watch the trace show up in Opik. This script uses LiteLLM, so you pick the provider with an environment variable and make no code changes.

1 · The script

It's included in this project at scripts/opik_inference.py:

scripts/opik_inference.py
import os, sys
import litellm
from opik import track

litellm.callbacks = ["opik"]                     # send calls to local Opik
os.environ.setdefault("OPIK_PROJECT_NAME", "quickstart")

@track                                       # group nested calls as one trace
def ask_llm(prompt):
    model = os.environ.get("LLM_MODEL", "gpt-5.6-luna")
    r = litellm.completion(model=model, messages=[
        {"role": "user", "content": prompt}])
    return r.choices[0].message.content

if __name__ == "__main__":
    print(ask_llm(" ".join(sys.argv[1:]) or "Hello!"))

2 · Pick a model & run

Choose your provider, set the variables, then run the script:

terminal
export LLM_MODEL="gpt-5.6-luna"
export OPENAI_API_KEY="sk-..."
python scripts/opik_inference.py "Explain an LLM trace in one sentence."
terminal
export LLM_MODEL="gemini/gemini-3.6-flash"
export GEMINI_API_KEY="..."
python scripts/opik_inference.py "Explain an LLM trace in one sentence."
terminal
# first: install ollama, then `ollama run llama3` once
export LLM_MODEL="ollama/llama3"
python scripts/opik_inference.py "Explain an LLM trace in one sentence."

3 · See the trace

Open localhost:5173, select the quickstart project, and open the newest trace. You'll see the prompt, the model's response, token counts, and latency.

✔ Verify before moving on
  • The script printed an answer in your terminal
  • A new trace appears under the quickstart project in the UI
